## Immersive Fixes 1.12.2
This mod is a mixin bundle of fixes for IE 1.12.2. Due to the major differences between 1.20.1 and 1.12.2, this is
listed as a separate project and not merely a separate branch. Separating the projects also has the added bonus of allowing
me to better focus on my time on fixing problems for the most popular present version instead of throwing work where it isn't
being used.
